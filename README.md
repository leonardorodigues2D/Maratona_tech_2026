# Fake News: Robux Grátis

Projeto desenvolvido para participação na **Maratona Tech**, com o objetivo de apresentar um site educativo sobre Fake News e golpes relacionados à promessa de Robux grátis no Roblox.

## Sobre o projeto

O site apresenta informações para ajudar os usuários a reconhecer informações falsas e identificar possíveis golpes na internet.

O conteúdo é dividido em diferentes páginas, abordando:

* O que são Fake News;
* O que são Robux;
* Análise de uma Fake News;
* Como evitar golpes;
* Conscientização sobre segurança na internet;
* Informações sobre os participantes do projeto.

## Tecnologias

O projeto foi desenvolvido utilizando:

* HTML5
* CSS3
* JavaScript

O JavaScript é responsável pela navegação entre as páginas, pelo funcionamento do menu lateral e pelo modo escuro.

O CSS foi desenvolvido com foco em organização visual, acessibilidade e responsividade, permitindo a utilização do site em diferentes tamanhos de tela.

## Objetivo

O principal objetivo é promover a conscientização sobre Fake News e golpes digitais, incentivando os usuários a verificar as informações antes de clicar, fornecer dados pessoais ou compartilhar conteúdos.

O projeto utiliza como exemplo os golpes que prometem Robux grátis para demonstrar como esse tipo de conteúdo pode enganar usuários.

## Público-alvo

O projeto é voltado principalmente para crianças e adolescentes que utilizam a internet e plataformas como o Roblox, mas as orientações apresentadas podem ser úteis para qualquer usuário.
